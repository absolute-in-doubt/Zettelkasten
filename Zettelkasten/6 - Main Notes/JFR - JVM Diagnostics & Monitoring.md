JFR - Java Flight Recorder

- Позволяет записывать данные постоянно - нет необходимости to reproduce a certain bug after it's caught in the production.
- Почти не имеет overhead

JFR Control:
- Comand line parameters
- POJO API
- JMX API
- [[jcmd - JVM Diagnostics & Monitoring|jcmd]]
- JDK Mission Control
