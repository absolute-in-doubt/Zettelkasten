# Справочники -1С

Предназначен для хранения почти неизменяемой Нормативно справочной информации (НСИ).



Можно получить через объект глобального контекста Метаданные:

`Метаданные.Справочники`

По сути `Метаданные.Справочники` - это `КоллекцияОбъектовМетаданных`

По нему можно итерироваться:

```python
&НаСервере
Процедура Команда1НаСервере()
	
	Для Каждого стрСправочника из Метаданные.Справочники Цикл
		
		Сообщить("Имя: " + стрСправочника.Имя 
		+ ", синоним: " + стрСправочника.Синоним);
		
	КонецЦикла
	
КонецПроцедуры

&НаКлиенте
Процедура Команда1(Команда)
	Команда1НаСервере();
КонецПроцедуры
```

> [!note]
> Объект [[Метаданные - 1С|Метаданные]] доступен только на сервере.

Сами свойства справочников не появляются в подсказках, когда пишиешь код, поэтому надо смотреть в самом окне свойств на названия полей.


### Доступ к реквизитам

Реквизиты - по сути тоже коллекция

```python
&НаСервере
Процедура Команда1НаСервере()
	
	РеквизитыСправочника = Метаданные.Справочники.Товары.Реквизиты;
	
	Для Каждого стрРеквизит из РеквизитыСправочника Цикл
		
		Сообщить("Имя: " + стрРеквизит.Имя + ", синоним: " + стрРеквизит.Синоним);
		
	КонецЦикла
	
КонецПроцедуры

&НаКлиенте
Процедура Команда1(Команда)
	Команда1НаСервере();
КонецПроцедуры
```
