В отличие от [[Spring Boot Actuator]] позволяет экспортить трейсы для Jaeger.

**Trace** — это полный путь выполнения одного запроса через систему. Он объединяет все операции, связанные с этим запросом, в разных сервисах, БД и внешних системах.

**Span** — отдельная операция внутри trace с информацией о времени начала/окончания, длительности, сервисе, операции и атрибутах. Например:

```text
Trace: POST /orders

├── API Gateway       10 ms
├── Order Service     50 ms
│   ├── PostgreSQL    15 ms
│   └── Kafka          5 ms
└── Payment Service   30 ms
```

Таким образом, **trace = дерево/граф связанных spans**, позволяющий понять, где именно потратилось время при обработке конкретного запроса.
