# Настройки поддержки - 1С


![[Pasted image 20260920112043.png|564]]



По умолчанию это "Редактируется с сохранением поддержки", это значит, что уже существующие объекты нельзя изменять:

![[Pasted image 20260920112208.png]]


И соответственно при [[Хранилище конфигураций - 1С|захвате из хранилища объекта]] мы не сможем его никак редактировать:

![[Pasted image 20260920112326.png|347]]



### Отображение статуса поддержки:

Правый замочек с какой-то желтой хуйней - значит, что объект не снят с поддержки и его нельзя редактировать.
Левый замочек значит, что объект не взят из хранилища и не захвачен с пессимистичной блокировкой.
