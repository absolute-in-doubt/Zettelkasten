# Метаданные - 1С

Метаданные - это объект, доступный в глобальном контексте на сервере или в толстом клиенте. (НЕ ДОСТУПЕН ИЗ ТОНКОГО КЛИЕНТА). Он позволяет получить информацию о Справочниках, Документах, Регистрах и т.д. (короче обо всех объектах).



> [!warning]
> Обычно бизнес-логику не делают зависимой от того, толстый это клиент или тонкий.
>
> Например, для `Метаданные` нормальный подход:
>
>```
>&НаКлиенте
>       ↓
>вызов серверной процедуры
>       ↓
>&НаСервере
>       ↓
>Метаданные....
>```

То есть для современной клиент-серверной разработки **лучше считать `Метаданные` серверным объектом** и обращаться к нему через серверный код, а не пытаться контролировать, каким клиентом пользователь запустил 1С.


---
### Метаданные vs Менеджер объектов

Ключевая разница: **`Метаданные` описывает структуру конфигурации**, а **менеджеры глобального контекста дают доступ к конкретным данным и операциям этой конфигурации**.

##### `Метаданные`

Это описание **того, что существует в конфигурации**:

```1c
Метаданные.Справочники.Товары
Метаданные.Документы.ЗаказКлиента
Метаданные.РегистрыНакопления.ОстаткиТоваров
```

Можно узнать, например:

- имя объекта;
    
- реквизиты;
    
- табличные части;
    
- типы реквизитов;
    
- формы;
    
- движения регистров и т.д.

**НО через Метаданные можно делать универсальный код не зная о конкретной существующей структуре конфигурации:**

Например, менеджер:

```
Справочники.Товары
```

заранее знает, что ты работаешь именно с `Товары`.

А через `Метаданные` можно сделать **универсальный код**, который не знает заранее, с каким справочником работать:

```
Для каждого СправочникМД Из Метаданные.Справочники Цикл
    Сообщить(СправочникМД.Имя);
КонецЦикла;
```

Получишь список **всех справочников конфигурации**.



#### Менеджер объекта

Может не просто просматривать существующую конфигурацию, но и взаимодействовать с объектом, изменяя его.

```1c
Справочники.Товары
Документы.ЗаказКлиента
РегистрыНакопления.ОстаткиТоваров
```

Это уже **менеджер конкретного объекта**, через который можно выполнять операции с данными:

```1c
Товар = Справочники.Товары.НайтиПоКоду("123");
```

или:

```1c
НовыйТовар = Справочники.Товары.СоздатьЭлемент();
```
