# XPath - Frontend


### Базовый синтаксис

- `/` — прямой путь (абсолютный), например `/html/body/div`. В автотестах почти не используется, так как хрупкий.
	
- `//` — поиск по всему документу (относительный путь). Это то, чем вы будете пользоваться постоянно. Например, `//div` найдет все дивы.
	
- `*` — любой тег. `//*[@id='main']` — найти абсолютно любой элемент с id равным `main`.


### **Шаг 2. Поиск по атрибутам (5 минут):**

- Синтаксис: `//тег[@атрибут='значение']`
	
- Примеры: `//input[@type='text']`, `//button[@id='submit-btn']`.


### **Шаг 3. Поиск по тексту и полезные функции (5 минут):**

- По толичному совпадению текста: `//a[text()='Sign In']`
	
- По частичному совпадению (очень выручает, когда текст динамический): `//span[contains(@class, 'error-')]` или `//button[contains(text(), 'Submit')]`.


### **Шаг 4. Относительные переходы (оси) (5 минут):**

- Родитель: `//input[@id='username']/parent::div`
	
- Предок: `//input[@id='username']/ancestor::form`
	
- Сосед (следующий): `//label[text()='Email']/following-sibling::input`
