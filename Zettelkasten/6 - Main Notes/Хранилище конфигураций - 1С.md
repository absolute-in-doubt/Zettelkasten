# Хранилище конфигураций - 1С

Хранилище конфигураций - это встроенный механизм контроля версий, предназначенный для организации коллективной разработки и сопровождения конфигураций платформы 1С:Предприятие.


Хранилище конфигураций решает следующие задачи:

- **Версионный контроль** - сохраняет полную историю всех изменений объектов конфигурации (справочников, документов, отчетов, обработок, форм, модулей) с фиксацией автора и временем внесения правок.
- **Возможность отката** - в любой момент можно восстановить предыдущую версию конфигурации или отдельного объекта при обнаружении ошибок.

- **Координация командной работы** - позволяет нескольким разработчикам безопасно работать с одной конфигурацией, исключая конфликты параллельного редактирования.
- **Контроль доступа к объектам** - реализует механизм пессимистичных блокировок: для редактирования объекта разработчик должен его "захватить", после чего объект становится недоступным для изменения другими участниками команды.


### Принцип работы

Хранилище представляет собой базу данных формата 1CD, содержащую только конфигурацию (метаданные), но не пользовательские данные (справочники, документы, движения по регистрам и т.п.)

Разработчики подключаются к хранилищу из своих рабочих баз, получая объекты для редактирования.


### Рабочий процесс

1. При подключении к хранилищу все метаданные из него загружаются в локальную базу разработчика.
2. Разработчик захватывает нужный объект для редактирования (объект блокируется для остальных)
3. После внесения изменений объект помещается обратно в хранилище с фиксацией версии.
4. Измененный объект становится доступным остальным участникам команды.

### Сохранение внесенных изменений в хранилище

Пока мы не поместим внесенные изменения в хранилище, никто другой их не увидит и блокировка объекта не будет снята.

![[Pasted image 20260920115023.png]]


![[Pasted image 20260920115028.png]]

В окне хранилища конфигурации жмем отбор и отбираем только те объекты, которые захвачены текущим пользователем хранилища (например, если мы залогинены в хранилище как администратор, и, соотвтественнно изменения внесены аккаунтом администратора, отбираем только их). Это просто, чтобы вручную не искать, все, что мы редактировали.

На отобранные объекты прожимаем ПКМ и жмем "Поместить в хранилище":

![[Pasted image 20260920115321.png]]

И проставляем галочку "Выполнить рекурсивно".

После подтверждения объект будет помещен в хранилище и блокировка будет отпущена. После этого другие пользователи должны обновить конфигурацию из хранилища:

![[Pasted image 20260920115510.png]]

И только тогда они увидят внесенные изменения и смогут захватить блокировку на объекте.



### Отображение статуса захвата объекта:

Правый замочек с какой-то желтой хуйней - значит, что объект не снят с поддержки и его нельзя редактировать.
Левый замочек значит, что объект не взят из хранилища и не захвачен с пессимистичной блокировкой.
