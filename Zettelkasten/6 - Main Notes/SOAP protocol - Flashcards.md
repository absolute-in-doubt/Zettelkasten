FILE TAGS: java+

Q: В каких случаях стоит использовать SOAP при разработке новой системы, а в каких - REST?
A:   
	
| Ситуация                                                               | Что выбрать                                |
| ---------------------------------------------------------------------- | ------------------------------------------ |
| Публичный/внутренний HTTP API для CRUD                                 | **REST**                                   |
| Микросервисная архитектура                                             | **REST** (или gRPC для service-to-service) |
| Нужно простое JSON API для frontend/mobile                             | **REST**                                   |
| Нужен строгий формальный контракт + XML/XSD                            | **SOAP**                                   |
| Интеграция с существующей SOAP-системой                                | **SOAP**                                   |
| Enterprise-интеграция с WS-Security, WS-*                              | **SOAP**                                   |
| Требуются стандартизированные SOAP-механизмы для enterprise-транзакций | **SOAP**                                   |
| Государственные/банковские системы с обязательным SOAP-контрактом      | **SOAP**                                   |
| Сложные legacy-интеграции                                              | **SOAP**                                   |
