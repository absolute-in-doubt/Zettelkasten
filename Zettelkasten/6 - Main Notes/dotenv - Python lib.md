# dotenv - Python lib


### Installation

Внутри [[Venv - Python|venv]]:

```shell
pip install python-dotenv
```


### Использование

Используется для загрузки .env файла из текуще директории. **Требует явного вызова метода библиотеки**


```python
from dotenv import load_dotenv

load_dotenv() # при вызове этого метода загрущит .env
```
