# Магические (Dunder) методы - Python


**Магические методы** — специальные методы Python с именами вида:

```python
__method__
```

Их ещё называют **dunder methods** (_double underscore_).

Они позволяют объектам участвовать в стандартных операциях Python.

### `__init__`

```python
class User:
    def __init__(self, name):
        self.name = name
```

При создании:

```python
user = User("John")
```

Python автоматически вызывает `__init__`.

> [!warning] 
> `__init__` **не создаёт объект**, а инициализирует уже созданный объект. За создание отвечает `__new__`.


---
### Другие распространённые

```python
__str__()    # str(obj), print(obj)
__repr__()   # repr(obj)
__eq__()     # obj1 == obj2
__lt__()     # obj1 < obj2
__len__()    # len(obj)
__getitem__()# obj[key]
__iter__()   # iter(obj)
__call__()   # obj()
```

Например:

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return self.name

    def __len__(self):
        return len(self.name)
```

Теперь:

```python
user = User("John")

print(user)  # вызывает __str__()
len(user)    # вызывает __len__()
```

---

### Есть ли у них особая видимость?

**Нет.** Двойное подчёркивание здесь не является механизмом `private`.

Можно напрямую вызвать:

```python
user.__str__()
user.__len__()
```

Но обычно этого не делают — предназначение таких методов в том, чтобы Python вызывал их **неявно через соответствующие операции**.


---
### Можно ли создать свой?

**Технически — да:**

```python
class User:
    def __hello__(self):
        print("Hello")
```

Но это **не сделает `__hello__` магическим методом**.

Python имеет определённый набор специальных методов и знает, когда их вызывать:

```python
user == other     # __eq__
len(user)         # __len__
str(user)         # __str__
```

Для произвольного `__hello__` никакого специального поведения не появится.

Поэтому обычно создают **свои обычные методы**, а не придумывают новые dunder-методы.

---

### Отдельно: `__name__`, `__file__` и т.д.

Не всё с `__...__` является методом:

```python
__name__
__file__
__dict__
```

Это специальные **атрибуты**, а не методы.

### Главное

> Dunder-методы — это специальный протокол взаимодействия объектов с Python. Их не нужно явно вызывать в большинстве случаев: `+`, `==`, `len()`, `str()`, `obj[key]` и другие операции автоматически используют соответствующие методы.
