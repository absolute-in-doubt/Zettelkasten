
Theory for the cards:  [[Классы - Python]]

FILE TAGS: python_core

Q: Что такое класс и объект в Python?  
A: Класс — это шаблон (blueprint) для создания объектов. Объект — это экземпляр класса, который хранит данные (атрибуты) и поведение (методы).

Q: Для чего нужен метод `__init__`?  
A: `__init__` — это конструктор класса. Он автоматически вызывается при создании нового объекта и инициализирует его атрибуты.
<!--ID: 1791903527088-->


Q: Что такое `self` в методах класса?  
A: `self` — это ссылка на текущий экземпляр объекта. Через `self` метод получает доступ к атрибутам и другим методам этого объекта.
<!--ID: 1791903527093-->


Q: В чём разница между атрибутом класса и атрибутом экземпляра?  
A: Атрибут класса (`Class.attr`) общий для всех экземпляров. Атрибут экземпляра (`self.attr`) уникален для каждого объекта.
<!--ID: 1791903527099-->


Q: Что такое инкапсуляция в Python?  
A: Инкапсуляция — это сокрытие внутренних данных класса. В Python используется соглашение: `_attr` (protected), `__attr` (private, name mangling).
<!--ID: 1791903527104-->


Q: Для чего нужен декоратор `@property`?  
A: `@property` позволяет обращаться к методу как к атрибуту (геттер). Позволяет добавлять логику при чтении/записи значения без изменения API класса.
<!--ID: 1791903527110-->


Q: Как реализовать наследование в Python?  
A: Указать родительский класс в скобках: `class Child(Parent):`. Дочерний класс наследует все атрибуты и методы родителя и может их переопределять.
<!--ID: 1791903527115-->


Q: Что такое `super()` и зачем он нужен?  
A: `super()` возвращает прокси-объект для вызова методов родительского класса. Используется для расширения, а не полной замены логики родителя.
<!--ID: 1791903527121-->


Q: Что такое полиморфизм?  
A: Возможность использовать объекты разных классов через единый интерфейс. Например, метод `speak()` работает и для `Dog`, и для `Cat`.

Q: Для чего нужны абстрактные классы (`ABC`)?  
A: Абстрактные классы задают интерфейс, который обязаны реализовать наследники. Нельзя создать экземпляр абстрактного класса напрямую.
<!--ID: 1791903527129-->


Q: Что делает декоратор `@dataclass`?  
A: Автоматически генерирует `__init__`, `__repr__`, `__eq__` и другие методы на основе аннотированных полей класса. Уменьшает бойлерплейт.
<!--ID: 1791903527135-->


Q: В чём разница между `@staticmethod` и `@classmethod`?  
A: `@staticmethod` не получает ни `self`, ни `cls`. `@classmethod` получает класс (`cls`) первым аргументом и может создавать экземпляры.
<!--ID: 1791903527141-->


Q: Что такое магические методы (dunder methods)?  
A: Методы вида `__method__` (например, `__str__`, `__add__`, `__len__`). Позволяют перегружать операторы и встраивать класс в стандартные функции Python.
